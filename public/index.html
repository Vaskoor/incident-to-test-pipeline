Architecture

🔔 Trigger — PagerDuty / Opsgenie / Sentry / Datadog webhook fires the pipeline
📦 Capture — OTel traces + Loki logs + Prometheus metrics + git diff at the incident time
🤖 Generate — LLM produces a failing test that reproduces the incident from the captured evidence
✅ Gate — test added to the regression suite + gated in GitHub Actions
🔁 Verify — once the fix ships, the test flips green; recurrence tracked
Stack: OpenTelemetry · Loki · Prometheus · LLM · GitHub Actions · PagerDuty
